# RUS PDF — Public Issue Tracker & Feedback

Welcome to the public issue tracker for **RUS PDF Editor**!

This repository does **not** contain application source code. It is the official public space for users, testers, and contributors to:
- 🐛 **Report bugs and defects**
- 💡 **Request new features and improvements**
- 💬 **Provide user experience feedback**

---

## 📌 Filing an Issue

To help us diagnose and fix issues quickly:

- **[Report a Bug](https://github.com/utarn/rus-pdf/issues/new?template=bug_report.yml)** — Please include your app version, operating system, clear reproduction steps, and any relevant error logs or sample files.
- **[Request a Feature](https://github.com/utarn/rus-pdf/issues/new?template=feature_request.yml)** — Describe the problem you are solving, your proposed workflow, and any mockups or examples.

---

## 🏷️ Issue Labels & Workflow

Issues submitted here go through an automated and maintainer-driven triage process:

### Triage States
- `needs-triage`: Newly submitted, waiting for initial triage and evaluation.
- `needs-info`: Waiting on the reporter for additional reproduction steps, logs, or sample files.
- `ready-for-agent`: Fully specified and ready for automated development in the codebase.
- `ready-for-human`: Requires manual developer action, UX design, or physical device testing.
- `in-progress`: Actively being investigated or worked on.
- `resolved`: Fixed in an upcoming or released build.
- `wontfix`: Out of scope or working as intended.

### Component Areas
- `area:pdf-editor`: PDF viewing, page manipulation, canvas rendering, text editing.
- `area:annotations`: Shapes, drawings, highlights, stamps, and note annotations.
- `area:ocr`: OCR text extraction, language data, recognition accuracy.
- `area:digital-signature`: Digital signatures, certificate verification, timestamping, LTV.
- `area:export-import`: Batch export, text conversion, file saving and loading.
- `area:license`: License activation, offline mode, renewal, account status.
- `area:ui-ux`: User interface, themes, localization, shortcuts, accessibility.

---

## 🔒 Security & Privacy

If your bug involves sensitive documents or confidential data, please redact personal information before uploading sample PDFs or logs.
